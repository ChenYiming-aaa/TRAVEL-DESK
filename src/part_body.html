使用说明
  • 地图交互：点击 / 悬停省份看足迹详情；点击城市像素点看到访记录；点未去省份可「标记为想去」；双击地图空白处复位；滚轮 / 双指缩放，拖拽平移。
  • 行程模块：新建行程后按日期生成每日计划框架，逐小时添加「时间 / 地点 / 做什么 / 时长 / 备注」；交通条目自动生成 12306 / 携程 / 去哪儿 搜索深链（不编造车次）；任务按截止日排序、勾选得经验；标记完成后会提示把新城市加入足迹。
  • 数据存储：全部数据保存在本机浏览器 localStorage，写操作即时落盘（防抖 300ms）；换设备 / 换浏览器用「导出 JSON 备份」与「导入恢复」迁移。
  • 离线使用：直接双击本 HTML 文件也能用，数据存在浏览器 localStorage；建议定期「导出 JSON 备份」。
  • 经验规则：新足迹 +10 EXP，完成任务 +15 EXP，完成行程 +50 EXP，解锁成就 +30 EXP，每 100 EXP 升 1 级（LV.1–30）。
